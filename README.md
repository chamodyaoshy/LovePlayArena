# 💖 LovePlay Arena

A fun, interactive Java Swing desktop application featuring 4 romantic mini-games designed for couples!

## 🎮 Included Games
1. ❌ **Tic-Tac-Toe** (Classic Love Battle)
2. ⚽ **Mini Football** (Goal Battle)
3. 🥏 **Couple Carrom** (Sweet Queen Strike)
4. 🏹 **Cupid Archery** (Shoot My Heart)

## 🛠️ Built With
* Java
* Java Swing & AWT

## 🚀 How to Run
1. Clone the repository.
2. Open in Eclipse IDE or IntelliJ IDEA.
3. Run `Main.java`.
